│   1. Briefing Service  (mais isolado, alto volume writes)                   │

│   3. User + Workspace  (low-churn, cache Redis)                             │
│                                                                               │
│ CENÁRIO B (Alternativo): 2 Microsserviços                                   │
│                                                                               │
│   ┌─────────────────────────────┐   ┌─────────────────────────────┐         │
│   │ Core Service                │◀─▶│ Platform Service            │         │
│   │ (Briefing + Proposal)       │   │ (Workspace + User)          │         │
│   └─────────────────────────────┘   └─────────────────────────────┘         │
│                                                                               │
│   Vantagem:  Menos overhead; FK briefing_id permanece intra-service         │
│   Desvantagem: Core fica grande; menor autonomia                            │
