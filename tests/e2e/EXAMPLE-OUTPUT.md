**Diagnosis:** JWT generated by user-service was rejected by the monolith with "Invalid JWT signature". This indicates JWT_SECRET mismatch between services.

**Fix:**
```bash
# Verify JWT secrets match
grep JWT_SECRET .env
grep JWT_SECRET user-service/src/main/resources/application.yml

# If different, synchronize
echo "JWT_SECRET=your-secret-here" >> .env

# Rebuild and restart
docker compose down
docker compose build --no-cache
docker compose up -d
```
